# مكتبة عيلام

المكتبة الرقمية لتاريخ وحضارة عيلام

کتابخانهٔ عربی اندروید با متن‌های Markdown، دسته‌های پویا از JSON، جست‌وجو، منابع، علاقه‌مندی‌ها، تنظیمات مطالعه و کش آفلاین IndexedDB. شامل ۱۶ مطلب، پنج عکس واقعی با اطلاعات مجوز و ۱۰ دستهٔ قابل‌ویرایش است.

## شروع سریع

```powershell
npm ci
npm run publish:content
npm run dev
```

ویرایشگر مستقل: `npm run editor`. پس از انتخاب پوشهٔ `content`، فرم‌ها را ویرایش و ZIP را دانلود کنید؛ سپس تغییرات را در GitHub ثبت کنید. ویرایشگر هیچ توکن یا امکان نوشتن مستقیم در GitHub ندارد.

## خروجی‌ها

- `dist/elam-library-1.0.0.apk`: خروجی استاندارد Capacitor، ساخته‌شده با موفقیت در GitHub Actions. امضا و SHA-256 تمام فایل‌های محتوای بسته بررسی شده‌اند؛ آزمون روی گوشی انجام نشده است.
- `dist/elam-library-1.0.0-light.apk`: خروجی جایگزین سبک، با رابط React و پوستهٔ بومی WebView.
- `android/`: پروژهٔ استاندارد Capacitor؛ `npm run android:sync` و سپس ساخت از Android Studio یا GitHub Actions.
- `dist/elam-digital-library-source.zip`: بستهٔ سورس بدون وابستگی‌ها، کش و کلیدهای خصوصی.
- `app/` و `build-apk.ps1`: پوسته و مسیر ساخت جایگزین خروجی سبک؛ این مسیر پوستهٔ Capacitor نیست.

ساخت محلی Capacitor به محدودیت فضای دیسک برخورد کرد؛ ساخت استاندارد روی GitHub Actions با موفقیت انجام شد. خروجی سبک و استاندارد دو پوستهٔ متفاوت دارند. گزارش آزمون‌ها و پیوند اجرای موفق در docs/ACCEPTANCE.md ثبت شده است.

## انتشار محتوا بدون ساخت APK

مخزن عمومی پروژه: [taranehirani73-droid/elam-digital-library](https://github.com/taranehirani73-droid/elam-digital-library). سورس و محتوا در شاخهٔ main ثبت شده‌اند. در Settings > Pages گزینهٔ GitHub Actions را انتخاب کنید. گردش `.github/workflows/content-pages.yml` فقط پس از اعتبارسنجی موفق، محتوا و ویرایشگر را منتشر می‌کند.

نشانی پیش‌فرض برنامه: `https://taranehirani73-droid.github.io/elam-digital-library/content/`. این نشانی فعال است و دریافت واقعی هر ۱۶ متن، پنج عکس و ۱۰ دسته از آن بررسی شده است؛ در تنظیمات برنامه قابل تغییر است. تا دریافت کامل نسخهٔ جدید، متن‌ها و تصاویر همراه APK در دسترس‌اند. هیچ دادهٔ خصوصی یا کلید امضایی به GitHub فرستاده نمی‌شود.

## ساختار

- `src/`: رابط خواننده، مدل اعتبارسنجی و همگام‌سازی
- `content/`: JSON و Markdown و تصاویر مالک
- `editor/`: ویرایشگر فرم‌محور مستقل
- `templates/`: قالب انواع محتوا
- `scripts/`: اعتبارسنجی، تولید فهرست عمومی و بسته‌بندی
- `tests/`: آزمون‌های مدل، جست‌وجو و کش و به‌روزرسانی
- `android/`: پروژهٔ Capacitor
- `.github/workflows/`: انتشار محتوا و ساخت Android
- `docs/`: راهنمای فارسی، معماری و وضعیت پذیرش

## بررسی

```powershell
npm run validate
npm test
npm run build
npm run build:editor
```

شش آزمون خودکار گذشتند. در مرورگر نیز جست‌وجو، صفحهٔ مقاله، اندازهٔ متن، علاقه‌مندی‌ها، ساخت دسته و داستان و خروجی ZIP بررسی شدند. دادهٔ معیوب جای نسخهٔ سالم کش را نمی‌گیرد. دسته و مطلب جدید با دریافت فهرست جدید ظاهر می‌شود؛ این رفتار با سرور شبیه‌سازی‌شده آزموده شده و دریافت از GitHub واقعی هنوز نیازمند انتشار مخزن است.

راهنمای کامل: [راهنمای فارسی](docs/راهنمای-فارسی.md). جزئیات محدودیت‌ها: [وضعیت پذیرش](docs/ACCEPTANCE.md). معماری: [ARCHITECTURE](docs/ARCHITECTURE.md).
